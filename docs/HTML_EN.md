# Web Console Deployment and Operation

English | [简体中文](HTML.md)

All web code is under `HTML/`. The interface includes a technology-themed gateway, an Nmap workspace, and a p0f workspace. The backend runs on **Tofino1**, while the p0f observation sensor runs on **nic-2**. The web application does not need to be installed on either NIC host.

## 1. Install an isolated web environment

From the project root on Tofino1, select an existing Python 3.9 or newer interpreter. Replace `python3.9` below with its absolute path if needed. Do not replace or globally upgrade the system/SDE Python 3.5 installation.

```bash
python3.9 -m venv .venv
.venv/bin/python -m pip install -r HTML/requirements.txt
```

If the switch cannot reach the package source, prepare wheels on a connected machine with the same OS, CPU architecture, and Python ABI:

```bash
python3.9 -m pip download -r HTML/requirements.txt -d wheels
```

Transfer them securely and install with `pip install --no-index --find-links /path/to/wheels -r HTML/requirements.txt`. Respect each dependency's license. Do not disable TLS verification to work around a certificate problem.

## 2. Configure and start

Complete initialization and all three builds in [DEPLOYMENT_EN.md](DEPLOYMENT_EN.md) first. The following management addresses are examples from the original testbed:

```bash
export SDE=/root/bf-sde-9.7.0
/usr/bin/python3 scripts/configure.py --sde "$SDE" \
  --web-host 0.0.0.0 --web-port 5080 \
  --switch-address 192.168.30.252 --sensor-address 192.168.30.131
.venv/bin/python scripts/web_service.py start
.venv/bin/python scripts/web_service.py status
```

Open `http://192.168.30.252:5080`. The first start creates a new administrative token. Read it in a Tofino terminal:

```bash
cat HTML/runtime/admin.token
```

Enter the token in the login dialog. Never commit it to Git or publish it in screenshots, manuals, or online notes. Do not reuse an access code from an earlier deployment. `HTML/runtime` contains private runtime state.

Logs:

```bash
tail -n 80 HTML/runtime/web.log
tail -n 80 HTML/runtime/data.log
tail -n 80 HTML/runtime/control.log
```

The start script does not terminate another service occupying port 5080. Identify the owner first. You can select another `--web-port`; pass `--switch-address` in the same configuration command so the sensor callback URL is regenerated.

For foreground debugging, run `bash HTML/run_dashboard.sh`; Ctrl+C stops only the web process. The background manager recognizes only the process it recorded with a matching PID and start time.

## 3. Nmap workspace

1. Enter Nmap from the gateway.
2. Select monitoring-forwarding or fingerprint-defense mode, then start it.
3. The confirmation dialog lists the current data/control-plane program names, PIDs, and commands. Only confirmation stops those processes; canceling aborts the new start. Obtain consent from other users of a shared switch.
4. The backend checks build files first, then starts the data plane, waits for device/BFRT readiness, starts the control plane, and confirms stable ports.
5. Run the scan from nic-1 as described in [NMAP_EN.md](NMAP_EN.md), and observe counters and sessions. Counts represent current rule matches and a session estimate; they are not a perfect measure of all scanning activity on the network.
6. After selecting a JSON profile, distinguish a saved selection from the fingerprint actually reported by the running control plane.

## 4. p0f workspace and sensor

Enter p0f from the gateway and log in. Opening the page does not start capture on nic-2 and does not modify SSH authorization on either host.

The sensor uses a dedicated token generated by this web instance and runs in nic-2 memory through existing SSH channels. Run the following command from a terminal that already has SSH access to both hosts. Replace `RELEASE_DIR` with the package's **actual absolute path** on Tofino1. This is a command parameter; no source path needs to change.

```bash
RELEASE_DIR=/absolute/path/to/OSDisguise
ssh -o BatchMode=yes P4 "/usr/bin/python3 '$RELEASE_DIR/HTML/tools/sensor_bundle.py'" \
  | ssh -o BatchMode=yes nic-2 'python3 - --background'
```

PowerShell equivalent:

```powershell
$ReleaseDir = '/absolute/path/to/OSDisguise'
ssh -o BatchMode=yes P4 "/usr/bin/python3 '$ReleaseDir/HTML/tools/sensor_bundle.py'" | ssh -o BatchMode=yes nic-2 "python3 - --background"
```

Configure the two SSH aliases beforehand, or replace them with real `user@host` targets. No new key from Tofino1 to nic-2 is required. Do not save the pipeline output because it contains the current sensor token. If SSH reports a host-key error, verify the server's identity instead of disabling host-key checking.

The sensor requires `/usr/sbin/p0f`, `/usr/bin/stdbuf`, `/sbin/ip`, and `enp5s0f1` on nic-2. After it prints `OSDisguise p0f sensor PID ...`, the web page should show its heartbeat. A duplicate start is rejected. The sensor does not take over or terminate an existing p0f listener.

Select monitoring-forwarding or p0f defense mode, then generate iperf2 traffic using [P0F_EN.md](P0F_EN.md). The page shows client handshake observations, signatures, and target comparisons for `.3.1 -> .3.2`. A separate command-line p0f listener can run at the same time; neither process takes over the other.

To stop the sensor, verify the PID printed by the start command on nic-2, then send TERM to that exact process:

```bash
ps -p <SENSOR_PID> -o pid,args
kill -TERM <SENSOR_PID>
```

The sensor stops only the p0f child it created. If the web server disappears, the sensor retries briefly, pauses capture after a sustained outage, and eventually exits. Stop it explicitly at the end of a formal demonstration.

## 5. Switching between Nmap and p0f

The modes share one ASIC, so only one can run at a time. Every change uses the same process-confirmation workflow and does not require recompilation. Nmap and p0f keep active profiles in separate directories, and p0f observations carry a runtime epoch so old events are not counted under a new mode.

## 6. Stop the web service

To end the entire demonstration, first use the page's stop button and confirm that the data and control planes have exited. Then stop the nic-2 sensor and any iperf or temporary HTTP services you started. Finally, from the project root on Tofino1:

```bash
.venv/bin/python scripts/web_service.py stop
.venv/bin/python scripts/web_service.py status
```

**Stopping the web service alone does not stop switch forwarding or fingerprint-defense programs.** Do not use `pkill python` or kill processes blindly by port. Restart the web service with the manager after configuration changes; stopping the ASIC program remains a separate, explicit action.

## 7. Security and display configuration

The administrative token is stored in `HTML/runtime/admin.token`, and the sensor token is stored in `HTML/runtime/p0f-sensor.token`. They are not interchangeable. Session authentication, CSRF validation, and sensor-source restrictions remain enabled. Flask's built-in server is intended for a trusted lab network, not direct Internet deployment.

`asset_label` in `config/deployment.json` defaults to the user-defined label `Linux 2.6`. The verified kernel defaults to `unverified`. After confirming it with `uname -r`, you can add `verified_kernel` and `verified_at` fields. These are manually verified records, not operating-system results detected live by the page.
