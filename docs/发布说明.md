## 许可证范围

按照作者选择，项目自有代码、新增部署脚本和文档采用 Apache-2.0，完整文本在根目录 `LICENSE`。作者名称暂写作 OSDisguise contributors；发布前可补充正式作者、单位及联系方式。第三方内容不因根目录存在 Apache 许可证而自动更换授权，见 `NOTICE`。

## 公共头文件

按作者要求，完整复现交付目录保留了 `common/util.p4`，没有删除或改写其中的厂商声明。实际与本机 SDE 9.7.0 `tna_counter/common/util.p4` 比对，差异仅为 `TofinoIngressParser` 声明的换行格式。作者说明声明是此前误粘贴，但此比对结果仍应在公开发布前核实权利来源。

不要直接把该文件标为 Apache-2.0。保守公开导出默认不包含它；使用者可从自己合法取得的匹配 SDE 中复制到 `common/util.p4` 后编译。项目参考过 `tna_counter/tna_counter.p4` 及其公共辅助文件，不分发厂商 SDK 源码树或二进制。

## 指纹与第三方素材

- `HTML/profiles/`、`HTML/profiles_p0f/`、`test_nmap/fps.json`、`test_p0f` 样例及 `HTML/validation/catalog/candidates.json` 为现有实验记录/候选。保留名称、字段和候选元数据，不把未经端到端验证的记录宣称为全部成功。
- Nmap 指纹数据涉及其数据文件条款，准确许可证随来源版本而定。请依据实际使用的 Nmap/数据库版本附带 LICENSE/COPYING，而非用最新版本条款替代旧版本。官方说明：[Nmap Legal Notices](https://nmap.org/book/man-legal.html)、[NPSL](https://nmap.org/npsl/)。
- p0f 签名同样需要核对所用发行版本及数据库来源：[p0f 官方页面](https://lcamtuf.coredump.cx/p0f3/)。
- `HTML/static/vendor/lucide.min.js` 保留文件自带 ISC 声明；页面位图位于 `HTML/static/images/`，发布者应确认素材的使用权。
- Flask 等 Python 依赖按 `requirements.txt` 单独安装，未把原工程的 vendor/wheel 目录塞入公开源码。

## 导出与发布检查

完整本地交付目录用于授权实验环境复现；公开仓库应先采用保守导出并完成来源核实：

```bash
/usr/bin/python3 scripts/export_source.py --output /tmp/OSDisguise-source.tar.gz
```

保守导出排除运行状态、部署私有配置、SDK 辅助头文件和未核实授权的指纹 JSON/位图。归档内 `PUBLIC_SETUP.md` 说明需要补齐的外部文件。这意味着该公开版不是带全量数据库的开箱即用版。

作者完成第三方授权确认后，才使用 `--include-profiles --include-sdk-helper --include-artwork` 生成含对应内容的交付包。选项仅表示发布者做出了授权判断，不代表脚本完成了法律审查。脚本仍不会包含任何运行密钥和历史数据。

发布前逐项核对：许可证适用范围；指纹/素材来源；是否包含令牌、SSH 私钥和真实抓包；源代码构建是否通过；README 的硬件前提是否完整；演示数据是否明确标为候选或实际验证结果。

发布流程不会开放实验平台公网访问、安装系统服务或发布任何运行凭据。GitHub 中只记录经过检查的源码与文档快照，不代表生产部署。
