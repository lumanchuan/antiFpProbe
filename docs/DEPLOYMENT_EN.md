# Deployment and Environment Checks

English | [简体中文](部署.md)

## 1. Hardware and three-host topology

The data plane must run on a **Tofino1 ASIC**. This project was validated with SDE 9.7.0. The deployer must install the SDK, driver, firmware, and platform-management libraries according to the device vendor's instructions; these components are not included in this repository.

| Host | Original management address (example) | Traffic address | Interface/port | Purpose |
|---|---|---|---|---|
| Tofino1 | 192.168.30.252 | No traffic IP required | Physical 10 <-> DEV60; physical 9 <-> DEV52 | Data plane, control plane, web console |
| nic-1 | 192.168.30.130 | 192.168.3.1/24 | enp5s0f1, physical port 10 | Nmap scanner, iperf client |
| nic-2 | 192.168.30.131 | 192.168.3.2/24 | enp5s0f1, physical port 9 | Scan target, p0f observer, iperf server |

The management network and traffic network are separate. Management addresses are used for SSH and the web console; they are not generated by the P4 program. Logical device ports can differ across switches, so verify the mapping with `show -a` at the `bf-sde.pm>` prompt. The current control planes configure DEV52 and DEV60 for 100G, RS FEC, and enabled state when the experiment is explicitly started. They do not automatically change Linux NIC drivers or IP addresses.

This release preserves the traffic addresses, ports, and MAC examples from the original experiment to avoid changing the algorithm. For another topology, review `configs/*.txt`, both control planes' port/MAC maps, `monitor/scan_monitor/scan_monitor.p4`, both HTML control-plane adapters, and the p0f capture filter. Editing only the deployment JSON does not rewrite the P4 forwarding relationship.

## 2. Software prerequisites

| Location | Software | Notes |
|---|---|---|
| Tofino1 | SDE 9.7.0, bf-p4c, bf_switchd, platform libraries | Must already drive the local ASIC correctly |
| Tofino1 | SDE-compatible system Python | Original testbed: `/usr/bin/python3`, version 3.5, with BFRT/PTF dependencies |
| Tofino1 | Python 3.9+ and venv | Used only by Flask; do not replace the system Python |
| nic-1 | Nmap, iperf2, iproute2 | Original Nmap version was 7.60; version and OS database affect recognition |
| nic-2 | p0f 3.x, iperf2, iproute2 | Output must be compatible with p0f 3 text format |

Install host-side tools with the package manager for the Linux distribution, for example the `nmap`, `p0f`, and `iperf` packages on Ubuntu/Debian. `iperf3` is not compatible with the `iperf` commands used here. Do not globally upgrade dependencies in the switch's system Python environment.

## 3. Read-only Linux NIC checks

On nic-1:

```bash
ip -br link show enp5s0f1
ip -4 addr show dev enp5s0f1
ip route get 192.168.3.2
ethtool -i enp5s0f1
ethtool enp5s0f1
```

On nic-2:

```bash
ip -br link show enp5s0f1
ip -4 addr show dev enp5s0f1
ip route get 192.168.3.1
ethtool -i enp5s0f1
ethtool enp5s0f1
```

Expected traffic addresses are `.3.1/24` and `.3.2/24`, with routes through the traffic interface. If another experiment bound the NIC to DPDK, the interface may disappear or the kernel may no longer own the traffic IP. Coordinate ownership before restoring it. This project never runs `dpdk-devbind`, writes IP addresses or routes, or modifies the firewall automatically.

## 4. Initialize local configuration

Log in to Tofino1 and enter the received project directory. All commands below use relative paths and continue to work if the directory is renamed.

```bash
export SDE=/root/bf-sde-9.7.0
/usr/bin/python3 scripts/configure.py --sde "$SDE"
```

The script creates `config/deployment.json` and private runtime directories, and seeds an initial profile for both modes. Re-running it does not overwrite an already selected active profile, but it does synchronize the forwarding files from `configs` into the HTML runtime area. It does not start a process, generate a fixed password, or modify the SDK.

To expose the console on a trusted internal network:

```bash
/usr/bin/python3 scripts/configure.py --sde "$SDE" \
  --web-host 0.0.0.0 --web-port 5080 \
  --switch-address 192.168.30.252 --sensor-address 192.168.30.131
```

Replace the management addresses for your testbed. The default bind address is `127.0.0.1`. If you expose it internally, use only an isolated trusted network and do not expose it directly to the Internet. Token authentication remains enabled in either configuration. The script does not change firewall or SSH settings.

## 5. First build

Locate an existing switchd configuration that is already known to start this physical device, and verify its `chip_list`, PCI information, and platform agent. The original testbed can use:

```bash
export PLATFORM_CONFIG="$SDE/install/share/p4/targets/tofino/antiFpProbe.conf"
/usr/bin/python3 scripts/build.py all --platform-config "$PLATFORM_CONFIG"
```

If this file does not exist, replace it with a working configuration from the local SDE. Do not copy a PCI path from another machine. The build script reads only the hardware section and combines it with this project's outputs to generate three independent configurations:

```text
build/nmap/antiFpProbe.conf
build/p0f/antiFpProbe_p0f.conf
build/monitor/scan_monitor.conf
```

Nmap uses `ENB_NMAP=1, ENB_P0F=0`; p0f uses the opposite values. Both retain the `antiFpProbe` program name for compatibility with the existing BFRT tables and control planes, while their build directories and runtime configurations remain separate. The monitoring-forwarding program is named `scan_monitor`.

The build does not run `make install`, overwrite an installed SDK program, or load the ASIC. Each mode writes `compile.log` in its build directory. Replace `all` with `nmap`, `p0f`, or `monitor` to build a single mode.

## 6. Diagnostics

```bash
/usr/bin/python3 scripts/doctor.py
```

The diagnostic checks the SDE, compatible Python/BFRT installation, all three build configurations and output paths, initial profiles, and the web port. Resolve failures before starting a control plane. This is read-only and does not stop other processes. It does not replace link, IP, ARP, and ping checks on the two NIC hosts.

## 7. After moving or renaming the directory

No source path needs to be edited. Set `SDE`, initialize the checkout, and regenerate absolute paths in the local build configurations:

```bash
/usr/bin/python3 scripts/configure.py --sde "$SDE"
/usr/bin/python3 scripts/build.py all --config-only --platform-config "$PLATFORM_CONFIG"
/usr/bin/python3 scripts/doctor.py
```

`--config-only` does not recompile the P4 programs. It requires the original `build/` outputs to remain complete and the SDK/hardware to be unchanged. A machine that receives only the public source must perform a normal first build. Python virtual environments are not reliably relocatable; recreate `.venv` after moving the directory.
